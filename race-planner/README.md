# TU:bit V2 2026全國競賽路徑規劃器

在網頁上以 **1 公分座標** 規劃 TU:bit V2 麥克納姆輪機器人的移動路徑與到點動作，自動產生可貼到
[兔比積木 Arduino IDE](https://tubitblock.trgreat.com/arduino-ide.html) 直接編譯燒錄的程式碼。
內建「2026 全國 AI 智創機器人競賽（扶輪盃）」兩項賽事場地，也可自訂空白場地。

目前版本：**v1.9.21**（完整更新紀錄見 [CHANGELOG.md](CHANGELOG.md)，網頁標題旁的版本號也可點開查看）

## 功能

- **場地**：物資能源爭霸戰 300×300、標靶爭奪賽 360×360（依實施計畫圖面換算），或自訂空白場地（30–2000 cm）。
- **路徑**：點場地新增路徑點 P1、P2…，可拖曳、設定車頭角度、弧線、速度與加減速。
- **到點動作**：在這裡夾取、在這裡放置、夾爪夾緊／張開、抬升、下降、旋轉夾爪、BNO 轉正、IR 校正、撞牆校正、超音波接近、發射、連續發射、砲台旋轉／仰角、等待；可逐一刪除、直接改角度；另有快速範本。
- **檢查**：車體碰撞與出界、模擬執行與時間估算、賽規檢查（車體尺寸、一次夾取 1 個、越界等）。
- **套件與感測器**：與課程網站「程式產生器」相同的 8 種套件（水平雲台、手臂 ATARM、發射器 PPGUN、超音波、BNO055、PS3、V7RC、IR 靠牆校正），含遙控設定與一鍵自動／手動模式。
- **程式碼**：與程式產生器共用同一套產生核心（依兔比積木擴充原始碼與官方範例）；已用 ESP32 核心 3.1.3 與兔比函式庫實際編譯驗證。
- **方案保存**：自動存在瀏覽器（localStorage），也可匯出／匯入 JSON 分享給學生。

## 部署到 GitHub Pages

本工具已收錄在 TU:bit V2 課程網站的 `race-planner/` 資料夾（競賽專區），隨課程網站一起部署即可（網址為 `https://你的帳號.github.io/儲存庫名稱/race-planner/`）。
**注意**：本資料夾的 `index.html`、`README.md`、`CHANGELOG.md` 只能放在 `race-planner/` 裡；放到網站根目錄會蓋掉課程首頁與整站更新紀錄，「← 競賽專區」連結也會失效。以下為單獨部署的方式：

1. 在 GitHub 建立新的 repository（例如 `tubit-path-planner`），設為 Public。
2. 把本資料夾內所有檔案上傳到 repository 根目錄：`index.html`、`README.md`、`CHANGELOG.md`、`.nojekyll`。
   （`.nojekyll` 是隱藏檔，網頁上傳若看不到，可用 GitHub Desktop 或「Add file → Create new file」建立一個空白的 `.nojekyll`。）
3. 進入 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約 1 分鐘後網址會顯示在同一頁，格式為：`https://你的帳號.github.io/tubit-path-planner/`

單一 `index.html` 即可運作，不需要建置步驟；字型由 Google Fonts 載入，離線時會自動改用系統字型。

## 使用流程

1. 最上方選賽事與機器人。
2. 「參數」分頁填車寬、車長、夾爪中心離車心距離，並拖曳或輸入起始位置。
3. 「套件與感測器」分頁勾選套件（手臂與發射器擇一、PS3 與 V7RC 擇一），設定遙控與一鍵自動／手動模式。
4. 按「畫路徑」，點場地新增路徑點；點物資會自動產生夾取，點放置區會自動產生放置。
5. 點選路徑點，用旁邊的「到點動作」工具列加入動作、設定車頭角度。
6. 看「賽規檢查」與紅色碰撞提示，按「模擬執行」確認。
7. 「程式碼」分頁按「複製程式碼」，貼到兔比積木 Arduino IDE 編譯燒錄。

**第一次使用請先燒錄「軸向測試程式」**：車子應依序前進 20 cm、右移 20 cm、逆時針轉 90°。方向不對時，到「參數 → 座標換算」調整。

比賽時（預設 PS3）：按 **START** 執行自動路線，做完 OLED 顯示 AUTO OK；舉手報告、裁判確認後按 **SELECT** 切回遙控。自動途中按 SELECT 會立刻中止。沒開一鍵自動模式時，按控制板 **A** 執行路線。

## 座標規則

- 原點 (0, 0) 在場地左下角，X 向右、Y 向上，單位 1 公分。
- 車頭 0° 朝上、90° 朝左、180° 朝下、-90° 朝右（逆時針為正）。
- BNO 轉正的目標角以開機時車頭為 0°、順時針增加，程式會自動換算。

## 注意事項

- 場地物件位置由實施計畫圖面換算，實際以大會公告與現場為準，可在網頁上拖曳或輸入修正。
- 「紅外線 IR 對牆校正 v1.0.0」函式庫只在兔比線上編譯伺服器，此部分依兔比網站產生的範本寫法，請在兔比網站實際編譯確認。
- 加入 PS3 或 V7RC 遙控後程式約占 89%–93% 程式空間，再加大型函式庫（如 OLED）可能放不下。
- 沒有勾選的元件，相關步驟會自動改成註解略過，避免編譯錯誤。

STEP 4　程式範例

把官方 .tb 範例拆成文字版積木，逐段說明每一塊在做什麼。積木名稱依 TubitBlock 介面意思改寫，顏色：事件、控制、TU:bit／MTC、擴充、運算。

本頁目錄 MTC 移動積木 MTC 參數設定 精準移動與弧線 測程法：轉 90° PS3 手臂車 PS3 發射車 V7RC 遙控車 BNO055 轉正 BNO 精準移動 PS3 無頭模式 練習任務 範例下載

MTC 移動積木（開迴路）

開迴路控制只送出馬達 PWM，不檢查實際走了多遠。電池電量、地面摩擦、車重都會造成誤差：例如設定前進 1 秒應走 10 cm，電量不足時可能只走 8 cm。

積木參數用途
MTC 角度移動角度、速度 −255～255往任一角度平移
MTC X Y 旋轉 移動X、Y、R 各 −255～255遙控最常用：X 橫移、Y 前後、R 旋轉
MTC V7RC 移動X、Y、左轉鍵、右轉鍵直接接 V7RC Game ADV 的搖桿值
停止所有馬達—失去連線時一定要停車

MTC 參數設定

  • 編碼器馬達規格：原廠齒輪比 1:90、編碼器 13 PPR。只有更換馬達型號時才需要改。
  • PID：基本上不用調整，除非車體太重造成馬達失步。調錯可能導致馬達燒毀。
  • 車體參數：輪寬、輪直徑、車體寬、車體長。改裝輪子或車架後要更新，精準移動才會準。

精準移動與弧線（閉迴路）

精準移動積木用編碼器回授，有「一般」與「進階」兩種；進階版可另外設定減速度、起始速度、結束速度。

速度單位是 deg/s（輪子每秒轉幾度）官方例子：720 deg/s＝每秒轉 2 圈。輪徑 6 cm 時周長約 18.8 cm，所以 720 deg/s ≈ 每秒 37.7 cm（官方講義以周長「約 18 cm」概算為 36 cm/s）。
  • 弧線控制（貝茲曲線）：由控制點決定的平滑路徑，不必「停→轉→走」，載物時更穩、整體更快。
  • 移動中斷：可設定中斷條件讓車子途中停下；再用「目標距離－已走距離」算出剩餘距離，繼續完成移動。

依據：官方 MTC V2 課程 01 基礎移動控制、02 MTC 參數設定、03 進階移動控制。

測程法：讓車子轉 90°

  1. 讓車子以固定速度旋轉 1 秒，目測轉了幾度（例如約 195°）。
  2. 算出每度需要幾秒：1 ÷ 195 ≈ 0.005128 秒／度。
  3. 轉 90° 需要：90 × 0.005128 ≈ 0.46 秒。

這是開迴路方法，電量變化就會有誤差。比賽建議改用精準移動的「旋轉」參數或 BNO055 轉正。

BNO055 轉正（修正版）

資料夾內的 轉正.tb 用自訂積木「BNO旋轉控制(deg)」：按 A 轉到 90°、按 B 轉到 180°。原寫法有兩個問題：

原寫法問題建議
重複直到 |目標 − 目前| ＝ 0.3角度是小數，幾乎不會剛好等於 0.3，可能一直轉不停改成 < 1（或 0.5）
誤差直接用「目標 − 目前」目標 0°、目前 350° 時誤差算成 −350，車子會繞一大圈誤差 > 180 減 360；< −180 加 360
比例係數 −1.65（轉正.tb）與 +1.25（校正 (1).tb）正負不同方向設反會越轉越偏先用小係數實測，轉錯方向就把正負對調
定義 BNO轉正 (deg) 插入原始碼 tubit.resetEnc(); 停止所有馬達 設定 err = deg − BNO055 讀取 orientationZ 如果 err > 180 → err = err − 360 如果 err < −180 → err = err + 360 重複直到 絕對值(err) < 1 MTC BNO 移動 編碼器 X=0 Y=0 Z=err × −1.65 目前Z=orientationZ 等待 0.005 秒 設定 err = deg − orientationZ（同樣做 ±360 修正） 插入原始碼 tubit.resetEnc(); 停止所有馬達

BNO055 以開機時的車頭為 0°。比賽時車子放好再開機，目標角度才會和場地方向一致。路徑規劃器產生的程式已內建 0°／360° 換算與停止條件。

BNO 精準移動（01_BNO精準移動.tb）

使用兔比積木線上版新版 MTC V3 擴充「MTC：BNO055 陀螺儀」分類的兩個積木（2026/10/04 查核擴充 v3.0.5）。按 A 後走邊長 50 cm 的正方形，每走一段同時左轉 90°，四段走完車頭剛好轉回原方向。

當 Arduino 啟動 TU:bit V2 初始化 BNO055 初始化 重複無限次 如果 按鈕 A 被按下 BNO 以目前方向設定移動起點 BNO 移動 x 0 y 50 (cm) 本段旋轉 −90° 最高速度 800 加速度 400 ← 往前 50 BNO 移動 x −50 y 0 本段旋轉 −90° 最高速度 800 加速度 400 ← 往左 50 BNO 移動 x 0 y −50 本段旋轉 −90° 最高速度 800 加速度 400 ← 往後 50 BNO 移動 x 50 y 0 本段旋轉 −90° 最高速度 800 加速度 400 ← 往右 50
積木產生的程式說明
BNO 以目前方向設定移動起點mtc.captureBnoStartFrame();把目前車頭當成 0°，並固定場地的 X／Y 方向。車子擺好後、每一組新動作開始前執行一次。
BNO 移動mtc.moveSCurveBno(x, y, 旋轉, 最高速度, 加速度, -(加速度), 0, 0);X／Y 依「起點」固定的方向移動，不會因為車頭轉了而跟著轉；旋轉是本段相對旋轉：−20 再 +20 回到原方向、0 維持方向、+720 右轉兩圈（正值右轉、負值左轉）。減速度自動等於負的加速度，起訖速度為 0。
和一般「MTC 移動」有什麼不同？一般 MTC 移動的 X／Y 以車頭為準，車子轉了 90° 之後「往前」也跟著變方向；BNO 移動以起點時的方向為準，而且全程用陀螺儀修正航向，所以邊走邊轉也能走出正方形。
程式會自動加入的設定第一次放進「BNO 移動」積木時，產生器會自動加入 BNO 角度讀取（readTuMtcBnoOrientationZ()）、開機最多等 5 秒讓 BNO055 就緒、航向 PID 設定（setYawReader、setHeadingPid、setHeadingSettle），不需要自己寫。
只有線上版新版 MTC 擴充有這兩個積木離線版或舊版 MTC V2.4 函式庫沒有 captureBnoStartFrame、moveSCurveBno，會編譯失敗。請在 兔比積木線上版 開啟，或用線上 Arduino IDE 燒錄。

試試看：把四段的旋轉都改成 0，車頭不動走正方形；改成 +90，邊走邊右轉；只改第一段為 +360，看車子邊走邊轉一圈。

產生的 Arduino 程式碼（已在兔比積木線上 Arduino IDE 編譯成功）
開啟兔比 Arduino IDE
// generated by OpenBlock
#include <Arduino.h>
#include <TuBitCore.h>
#include <Wire.h>
#include <EasyBNO055_ESP.h>
#include <TuMTC.h>
#include <math.h>

TuBitCore tubit;
EasyBNO055_ESP bno;
TuMTC mtc(tubit);
struct TuMtcBnoReadyCompat {
 template <typename SensorT>
 static auto read(SensorT &sensor, int) -> decltype(sensor.isReady(), bool()) {
 return sensor.isReady();
 }
 template <typename SensorT>
 static bool read(SensorT &, long) {
 return true;
 }
};
double readTuMtcBnoOrientationZ() {
 return TuMtcBnoReadyCompat::read(bno, 0) ? bno.orientationZ : NAN;
}

void setup() {
  tubit.init();
  bno.start();
  unsigned long tuMtcBnoWaitStart = millis();
  while (!TuMtcBnoReadyCompat::read(bno, 0) && millis() - tuMtcBnoWaitStart < 5000UL) {
   delay(20);
  }
  mtc.setYawReader(readTuMtcBnoOrientationZ);
  mtc.setYawDirection(1);
  mtc.setHeadingPid(3.0, 0.0, 0.03, 120.0, 60.0);
  mtc.setHeadingSettle(1.0, 100, 1500);
}

void loop() {
  if (tubit.readButton(Button_A)) {
    mtc.captureBnoStartFrame();
    mtc.moveSCurveBno(0,50,(-90),800,400,-(400),0,0);
    mtc.moveSCurveBno((-50),0,(-90),800,400,-(400),0,0);
    mtc.moveSCurveBno(0,(-50),(-90),800,400,-(400),0,0);
    mtc.moveSCurveBno(50,0,(-90),800,400,-(400),0,0);
  }
}

MTC＋BNO＋PS3 無頭模式（02_MTC_BNO_PS3無頭模式控制.tb）

「無頭模式」也叫場地座標控制：左搖桿往上推，車子永遠往開機時的前方走，不管車頭現在轉到哪裡。操作手不用在腦中換算車頭方向，邊旋轉邊直線移動也很直覺。

當 Arduino 啟動 TU:bit V2 初始化 BNO055 初始化 PS3 初始化 MAC 10:00:00:02:22:67 重複無限次 如果 PS3 已連線 MTC 無編碼器 移動 x 左搖桿 X × 0.85 y 左搖桿 Y × −0.85 旋轉 右搖桿 X × 0.85 目前角度 BNO055 讀取 orientationZ 等待 0.005 秒 否則 停止所有馬達 ← 手把斷線就停車
積木／寫法產生的程式說明
MTC 無編碼器 移動（帶目前角度）mtc.bnoMoveOpen(x, y, 旋轉, bno.orientationZ);依「目前角度」把搖桿方向換算成車身方向，所以移動方向跟著場地走，不跟著車頭走。這就是無頭模式的關鍵。
左搖桿 Y × −0.85Ps3.data.analog.stick.ly * -0.85搖桿往上推時 ly 是負值，乘上負號才是前進；0.85 讓最高速度約 85%，比較好控制。
否則 → 停止所有馬達tubit.stopAllMotors();手把斷線時立刻停車，安全必備。
和官方 PS3 手臂車有什麼不同？官方範例用 mtc.driveVectorOpen(...)，搖桿方向以車頭為準（第一人稱）；本範例用 mtc.bnoMoveOpen(..., bno.orientationZ)，方向以開機時的場地方向為準（第三人稱）。
使用前注意① 開機那一刻的車頭方向就是「前方」，比賽時車子擺正再開機；角度飄掉時重新開機即可歸零。② MAC 改成自己手把記住的位址。③ BNO055 沒接好時 bno.start() 會一直等，程式卡在開機，手把也連不上；請先確認 BNO055 的 I2C 位址 0x28 有回應。
產生的 Arduino 程式碼（已在兔比積木線上 Arduino IDE 編譯成功）
開啟兔比 Arduino IDE
// generated by OpenBlock
#include <Arduino.h>
#include <TuBitCore.h>
#include <Wire.h>
#include <EasyBNO055_ESP.h>
#include <Ps3Controller.h>
#include <TuMTC.h>

TuBitCore tubit;
EasyBNO055_ESP bno;
TuMTC mtc(tubit);

void setup() {
  tubit.init();
  bno.start();
  Ps3.begin("10:00:00:02:22:67");
}

void loop() {
  if (Ps3.isConnected()) {
    mtc.bnoMoveOpen((Ps3.data.analog.stick.lx * 0.85), (Ps3.data.analog.stick.ly * -0.85), (Ps3.data.analog.stick.rx * 0.85), bno.orientationZ);
    delay(0.005 * 1000);
  } else {
    tubit.stopAllMotors();
  }
}

練習任務

走正方形

邊長 50 cm：前進 → 右移 → 後退 → 左移，車頭方向不變。

走菱形

邊長 50 cm：只用斜向移動（右前、右後、左後、左前）。

精準轉 90°

分別用測程法、精準移動旋轉 90°、BNO 轉正，比較誤差。

BNO 邊走邊轉

用「BNO 移動」走 50 cm 正方形，比較每段旋轉 0°、−90°、+90° 時終點的誤差。

無頭模式繞錐

用 PS3 無頭模式，車頭一直原地旋轉，同時把車子直線開到 1 公尺外的目標。

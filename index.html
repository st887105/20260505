研習救星

  1. 複製書籤網址。

    正在準備書籤…

  2. 在 Chrome 按 Ctrl + Shift + O 開啟書籤管理員。新增或編輯「研習救星」書籤，將複製的內容貼到「網址」欄並儲存。
  3. 書籤儲存後，開啟要使用的研習網站並登入。
    • 教育部磨課師
    • 特殊教育專業發展（普特合作教師篇）
  4. 開啟已報名的課程，按「開始學習」或「已報名開始學習」，進入課程學習頁。
  5. 留在課程學習頁，點 Chrome 的「研習救星」書籤，從選單選擇目前的平台。
操作截圖
Android 手機 Chrome
  1. 複製書籤網址後，從 Chrome 選單把本頁加入書籤。到「書籤」編輯該項，將名稱改為「研習救星」，並貼上複製的網址。
  2. 進入研習網站的課程學習頁。在網址列輸入書籤名稱，如果出現「研習救星」書籤建議，點該筆建議開啟選單。

實際能否啟動取決於手機 Chrome 版本。若沒有出現書籤建議，可改用桌面 Chrome。

磨課師會讀取最新發布的版本。特教助手更新後，請回到此頁重新複製書籤網址。
